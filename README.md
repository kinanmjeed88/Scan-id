# مستمسكات — Scan ID

تطبيق Flutter مستهدف لـ **Windows وAndroid** لتنظيم مستمسكات محلياً، ثم قصّها وترتيبها للطباعة على A4 على مراحل.

> **الحالة: دفعة تأسيسية غير معتمدة بعد. ليست تطبيق القص والطباعة المكتمل.**
> بدأ المستودع بملف README فقط. لم تتوفر Flutter/Dart أو Android SDK في بيئة التنفيذ، وتعذر تنزيلها. لا يوجد APK/EXE أو نتيجة `flutter analyze`/`flutter test` ناجحة بعد. راجع [تقرير الحالة](docs/STATUS.md).

## ما أُضيف إلى الشيفرة

- واجهة عربية لإنشاء المشاريع، عرضها، إعادة فتحها، إعادة تسميتها وحذف بياناتها.
- قاعدة Sembast محلية، حفظ فوري لكل عملية ناجحة، ورقم مراجعة يمنع الكتابة فوق حالة أحدث.
- استيراد متعدد لـ JPEG/PNG، حفظ الأصل بايتياً، نسخة عمل PNG مصححة اتجاه EXIF وصورة مصغرة؛ المعالجة في isolate.
- مكتبة صور، معاينة الأصل/نسخة العمل، وتكبير العرض. لا تعديل مدمر للأصل.
- نموذج مستقل عن Flutter: A4 بالـ mm، هوامش، عناصر وأبعاد وزوايا، بيانات القص، إعدادات تخطيط وتصدير، وسجل تراجع محدود. **وجود النموذج لا يعني توفر محرر أو تصدير.**
- اختبارات مكتوبة للنموذج، القياسات، الهندسة، التخزين والاستيراد والواجهة؛ **لم تُشغل هنا**.
- سياسات Android تمنع النسخ الاحتياطي التلقائي، وتخزين Windows تحت LocalAppData بدلاً من RoamingAppData.

## ما لم يُنفذ بعد

الكاميرا، القص اليدوي والذكي، تصحيح المنظور الفعلي، تحسين الصور، محرر A4، الترتيب الذكي/اليدوي، التراجع في الواجهة، PDF/JPG/PNG للورقة، الطباعة، النسخ الاحتياطي/الاستعادة، التثبيت والتوقيع واختبارات الأجهزة. لا توجد أزرار أو نتائج وهمية لهذه الوظائف.

## التجهيز الأول

الخط الأساسي **Flutter 3.35.7 / Dart 3.9**. تحتاج Windows + Visual Studio بمكوّن **Desktop development with C++** لبناء Windows. تحتاج JDK 17 وAndroid SDK وأذوناته لبناء Android.

ملفات native runners غير مولّدة بالكامل هنا لغياب SDK؛ الموجود في `android/` هو سياسة manifest/النسخ الاحتياطي فقط. السكربت يولّد runners الرسمية في **هذا المشروع نفسه** دون `--overwrite`، فلا يستبدل `lib/` أو الاختبارات أو pubspec. لا يُنشئ تطبيقاً موازياً.

### Windows (PowerShell)

```powershell
flutter --version
flutter doctor -v
.\tool\bootstrap.ps1
# راجع pubspec.lock الناتج واحتفظ به في المستودع بعد نجاح حل الاعتماديات.
.\tool\verify.ps1
flutter run -d windows
flutter build windows --release
```

### Android (مضيف Linux/macOS أو Windows)

```bash
flutter doctor -v
flutter doctor --android-licenses
bash tool/bootstrap.sh
# راجع pubspec.lock الناتج؛ لا يوجد lockfile مختلق في الدفعة الحالية.
bash tool/verify.sh
flutter devices
flutter run -d <android-device-id>
flutter build apk --release
```

على Windows استخدم سكربتات PowerShell بدلاً من Bash. أول إعداد وتنزيل Flutter/الاعتماديات يحتاج الإنترنت؛ **تشغيل التطبيق نفسه مصمم دون شبكة**. بناء Android الافتراضي يستخدم توقيع تطوير إلى أن تُضبط مفاتيح الإصدار محلياً؛ ليس نسخة إنتاج جاهزة للتوزيع. لا تضف مفاتيح توقيع إلى Git.

### أوامر بوابة الجودة

```bash
dart format lib test
dart format --output=none --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test --coverage
```

لا تنتقل إلى مرحلة القص قبل نجاح هذه البوابة. يحتوي `.github/workflows/verify.yml` تعريف اختبار على Ubuntu وWindows، ثم بناء المنصة فقط بعد نجاح الاختبارات. **لم يُشغّل workflow في هذه الجلسة**. شغّله بعد رفع الفرع بالطريقة المعتادة؛ لا تعتبر وجود الملف دليلاً على نجاح البناء.

## التخزين والسلامة

- Windows: `%LOCALAPPDATA%\ScanId\scan_id`.
- Android: مجلد دعم التطبيق الخاص، ثم `scan_id`؛ دون أذونات تخزين واسعة.
- `projects.db`: بيانات المشروع، `projects/<id>/assets/<id>/`: أصل + نسخة عمل + صورة مصغرة.
- استيراد حتى **20 MiB** و**16 مليون بكسل** لكل صورة، و200 صورة للمشروع. هذه حدود احترازية، وليست ضمان أداء مقاساً على هاتف.
- الصور المتحركة، HEIC، WebP، TIFF وPDF غير مدعومة في هذه الدفعة.
- لا تُستنتج المقاسات الفيزيائية من الصور؛ الصور المستوردة غير موضوعة تلقائياً على A4.
- الحذف الحالي **حذف بيانات/مراجع فقط**. تبقى ملفات الصور المملوكة للتطبيق، ولا يوجد تنظيف ملفات يتيمة أو استرداد من الواجهة بعد. قد تزداد المساحة المستهلكة؛ لا تستخدم هذه النسخة كأرشيف إنتاجي.
- إلغاء تثبيت التطبيق أو حذف مساحة بياناته قد يفقد المشاريع. النسخ الاحتياطي داخل التطبيق لم يُنفذ.
- الأصل المحفوظ يحتفظ ببيانات EXIF إن وجدت. لا تشفير إضافي ولا رفع/تحليلات شبكية. سياسات النسخ الاحتياطي تحتاج اختبار OEM، كما لا يستطيع التطبيق منع برامج النسخ الاحتياطي الخارجية التي يشغّلها المستخدم/مسؤول الجهاز.
- قد يترك انقطاع العملية ملفات يتيمة، لكن لا يُعتمد سجل صورة قبل كتابة الملفات. لا ضمان بعد ضد فقد البيانات عند قطع الطاقة؛ يلزم اختبار تعطل فعلي.
