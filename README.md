# مستمسكات — Scan ID

تطبيق Flutter محلي لـ **Windows وAndroid** لتنظيم المستمسكات وقصّها، تمهيداً لترتيبها وطباعة A4.

> **نسخة تطوير؛ طلب السحب مسودة ولم يُعتمد إصدار إنتاجي.**
> أحدث بوابة ناجحة قبل الإضافات الأخيرة: [`b25bd40` / تشغيل37463296066](https://github.com/kinanmjeed88/Scan-id/actions/runs/37463296066). حماية PNG وفحوص الشبكة المعزولة ومحاكي Android الجديدة تنتظر التحقق. انظر [الحالة الحالية](docs/STATUS.md)؛ البناء ليس إثباتاً لتجربة جهاز أو طابعة فعلية.

## الوظائف الموصولة حالياً

- واجهة عربية RTL لإنشاء المشاريع، إعادة فتحها وتسميتها وحذف بياناتها.
- Sembast محلي؛ حفظ العمليات الناجحة ومراجعات تمنع الكتابة فوق حالة أحدث.
- استيراد متعدد لـ JPEG/PNG: نسخة أصل مطابقة بايتياً، نسخة عمل PNG مصححة اتجاه EXIF وصورة مصغرة. المعالجة الثقيلة في isolate.
- معاينة الأصل ونسخة العمل مع التكبير، دون استبدال الأصل الخارجي أو المحلي.
- محرر أربع زوايا، اقتراح حدود محلي يمكن تعديله أو رفضه بالتراجع، وتصحيح منظور فعلي. دوران بمضاعفات 90°، سطوع وتباين، ونسب أبعاد اختيارية.
- معاينة إلزامية قبل اعتماد القص؛ أي تعديل يبطل المعاينة السابقة. تراجع/إعادة أثناء جلسة القص، وتأكيد عند مغادرة تعديلات غير محفوظة. إعادة التحرير تقرأ الأصل دائماً، لا نتيجة المعالجة السابقة.
- عند الاعتماد: ملفات PNG/thumbnail جديدة ثم حفظ بيانات المشروع؛ الأصل والنسخ السابقة لا تُستبدل. سجل التراجع داخل الجلسة فقط، وليس واجهة تاريخ دائم.
- محرر A4 بالمليمتر: سحب، تغيير المقاسات، دوران، محاذاة، توزيع، نسخ وحذف، قفل، تكبير وتحريك مساحة العمل، وتراجع/إعادة مع الحفظ.
- اقتراح ترتيب قابل للمراجعة والرفض، يحترم الهوامش والمسافات والقفل ويبيّن العناصر غير الموضوعة.
- معاينة نهائية وتصدير PDF متعدد الصفحات وPNG/JPG بدقة300/600DPI، مع اختيار الصفحات وطباعة عبر النظام.
- نسخ احتياطية كاملة متدفقة `.scanid` واستعادة بمشروع مستقل والتحقق من البصمات والمسارات.
- كاميرا Android النظامية وسجل التقاط قابل للاسترداد دون تكرار الصورة بعد انقطاع الحفظ.
- نقاط استرداد محلية للبيانات، وإعادة بناء النسخ المعالجة من الأصول ووصفات القص؛ لا تحل النقاط المحلية محل نسخة احتياطية خارجية.

### تجربة القص

أنشئ مشروعاً ← استورد JPEG/PNG ← افتح إجراء القص للصورة ← اسحب الزوايا أو جرّب «اقتراح الحدود» ← راجع/عدّل أو تراجع ← «معاينة التصحيح» ← «اعتماد القص وحفظ».

اقتراح الحدود heuristic وليس كشفاً مضموناً لكل صورة. اختيار النسبة لا يثبت المقاس الفيزيائي للمستمسك، ولا تعيد زيادة البكسلات تفاصيل مفقودة. راجع النصوص والوجوه قبل الاعتماد.

## حدود التحقق المتبقية

الفحوص الجديدة لم تجتز بوابتها بعد. لم تُجرَ تجربة استخدام يدوية كاملة على Windows أو هاتف Android، أو طباعة مادية، أو اختبارات انقطاع طاقة/امتلاء قرص حقيقي. لا installer أو توقيع إنتاجي، ولا تشفير للنسخ الاحتياطية. لا تُعدّ فحوص الخدمة المحقونة اختباراً لكاميرا حقيقية.

## التشغيل والبناء

الخط الأساسي المثبّت **Flutter 3.35.7 / Dart 3.9**، وليس ادعاءً بأنه أحدث إصدار. `pubspec.lock` وrunners Android/Windows مولدة بواسطة SDK فعلي، ومراجعة ومضافة إلى المستودع. bootstrap يحافظ عليها، ولا يعيد إنشاء التطبيق أو يستبدل الملفات الموجودة.

### Windows (PowerShell)

يلزم Windows وVisual Studio مع **Desktop development with C++** وWindows SDK.

```powershell
flutter --version
flutter doctor -v
.\tool\bootstrap.ps1
.\tool\verify.ps1
flutter run -d windows
flutter build windows --release
```

التوزيع الحالي portable غير موقّع: احتفظ **بكل** ملفات `build/windows/x64/runner/Release/` معاً، وليس `scan_id.exe` وحده.

### Android

يلزم JDK 17 وAndroid SDK وتراخيصه، على مضيف Linux/macOS أو Windows. APK الحالي يتطلب Android API 24 أو أحدث وفق فحص الملف المبني.

```bash
flutter doctor -v
flutter doctor --android-licenses
bash tool/bootstrap.sh
bash tool/verify.sh
flutter devices
flutter run -d <android-device-id>
flutter build apk --release
```

على Windows استخدم سكربتات PowerShell. الناتج: `build/app/outputs/flutter-apk/app-release.apk`. توقيعه الحالي **تطويري، وليس توقيع توزيع إنتاجي**. لا تضف مفاتيح توقيع إلى Git.

أول تنزيل SDK/الاعتماديات يحتاج الإنترنت؛ تشغيل التطبيق مصمم محلياً دون شبكة. لا يُستبدل اختبار الجهاز الفعلي ببناء CI.

### بوابة الجودة

```bash
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed .
flutter analyze --fatal-infos
flutter test --coverage
```

يشغّل `.github/workflows/verify.yml` البوابة على Ubuntu وWindows، ثم يبني APK على Linux وWindows على Windows. يضيف فحص خصوصية **APK المبني** وفحص بدء تشغيل EXE بقاعدة بيانات معزولة. لا تُعتبر إضافة الفحوص إثبات نجاحها: النتائج مرتبطة بالـ SHA في [STATUS](docs/STATUS.md). مخرجات البناء متاحة ضمن Artifacts للتشغيل الناجح؛ لا ملفات SDK أو APK/EXE ضخمة في Git.

### حزم البناء

توجد حزم `android-development-release` و`windows-unsigned-portable` في Artifacts لـ[آخر تشغيل متحقق قبل الإضافات الجديدة](https://github.com/kinanmjeed88/Scan-id/actions/runs/37463296066). تخص `b25bd40`، وليست دليلاً على نجاح HEAD اللاحق. قد يتطلب التنزيل الدخول إلى GitHub.

## التخزين والسلامة

- Windows: `%LOCALAPPDATA%\ScanId\scan_id`؛ Android: مجلد دعم التطبيق الخاص ثم `scan_id`، دون إذن تخزين واسع.
- `projects.db`: بيانات المشروع. `projects/<project>/assets/<asset>/`: الأصل والعمل والصورة المصغرة. نسخ القص تحت `edits/<revision>/`.
- المخطط الحالي **3**؛ قراءة الإصدارين1/2 مدعومة. الإصدارات غير المعروفة تُرفض ولا تُمسح القاعدة. تشمل البيانات صفحات الورقة وإيصال التقاط اختياري. نقاط الاسترداد تحت `checkpoints/`؛ الاسترداد الصريح يختار قاعدة جديدة عبر `active-store.json` دون حذف القديمة.
- حد الصورة **20 MiB / 16 مليون بكسل**، و200 صورة للمشروع. ليست هذه ضمانات peak memory أو سرعة على هاتف.
- لا HEIC/WebP/TIFF/PDF أو صور متحركة. لا استنتاج تلقائي للمقاس الحقيقي؛ الترتيب المقترح يتطلب مراجعة المستخدم.
- الحذف يزيل البيانات/المراجع فقط؛ ملفات الصور تبقى. لا GC أو استعادة للمحذوف من الواجهة؛ قد تتزايد مساحة الملفات والنسخ اليتيمة بعد فشل حفظ.
- إلغاء التثبيت/حذف بيانات التطبيق قد يفقد المشاريع. احفظ نسخة `.scanid` في موقع محلي آمن خارج مساحة التطبيق؛ تحتوي الأصول ونسخ المعالجة والبيانات دون تشفير.
- الأصل يحتفظ بـ EXIF. لا تشفير إضافي أو رفع أو تحليلات شبكية. سياسات Android لا تمنع برامج النسخ الاحتياطي الخارجية التي يشغّلها المستخدم/مسؤول الجهاز، وتحتاج تحقق OEM.
- فشل قاعدة البيانات بعد كتابة ملفات القص يترك نسخة يتيمة آمنة، لا يستبدل الأصل. لم تُختبر بعد حالات قطع الطاقة وامتلاء القرص الحقيقي والمدخلات العدائية الشاملة.
