# أداة التوسيم المرجعي المحلية على Android

هذه طبعة مستقلة باسم **استوديو الوسوم المرجعية** ضمن تطبيق Scan-id. وهي مخصصة لفجوة التوسيم المرجعي فقط؛ لا تنفّذ OCR أو تدريباً أو تعديلات على كاشف الوثائق.

## البناء والتشغيل

يتطلب **بناء** التطبيق Flutter 3.35.7 وAndroid SDK. طبعة المسح المعتادة بقيت على flavor `scanid`، أما الأداة المحلية فتُبنى هكذا:

```sh
flutter build apk --flavor annotator --debug --target lib/reference_annotation/main.dart
# أو على جهاز تطوير متصل لمعاينة التطبيق:
flutter run --flavor annotator --target lib/reference_annotation/main.dart
```

بعد تثبيت التطبيق، يختار المستخدم الصور ويحرر الوسوم ويستعيدها من الهاتف نفسه؛ لا يحتاج إلى حاسوب أو Python أو ADB أو خادم محلي أثناء الاستخدام. طبعة `annotator` تحذف صلاحيات Android من بيانها المدمج، بما فيها `INTERNET`، ويختبر CI هذا الشرط. **لم يُجر اختبار على جهاز Android فعلي ضمن هذا التغيير.**

### التثبيت باستخدام الهاتف فقط

لا يحتاج التثبيت من APK التجريبي إلى حاسوب، لكنه يتطلب اتصالاً لتنزيل ملف APK مرة واحدة وحساب GitHub لديه صلاحية للمستودع:

1. من الهاتف افتح [تشغيلات التحقق للفرع](https://github.com/kinanmjeed88/Scan-id/actions/workflows/verify.yml?query=branch%3Aarena%2Ff82991bf-scan-id)، ثم اختر أحدث تشغيل ناجح للالتزام المطلوب على `arena/f82991bf-scan-id`.
2. من قسم **Artifacts** نزّل `scan-id-reference-annotator-debug-apk` إلى الهاتف. الأداة ترفع هذا الـAPK التجريبي لمدة 7 أيام فقط بعد نجاح البناء وفحص manifest؛ لا تستخدم APK من تشغيل فاشل أو قديم.
3. افتح تطبيق **الملفات** في Android، واستخرج ملف ZIP، ثم اضغط `app-annotator-debug.apk`.
4. إذا طلب Android ذلك، اسمح مؤقتاً لمتصفحك أو تطبيق الملفات بتثبيت تطبيقات غير معروفة من هذا المصدر، وأكمل التثبيت. ألغِ هذا السماح بعده إن رغبت.
5. افتح **استوديو الوسوم المرجعية**. بعد التثبيت لا يحتاج العمل إلى الإنترنت أو كمبيوتر أو Python أو ADB أو خادم محلي. هذا بناء debug للاختبار المحلي، وليس إصدار متجر أو بناء إصدار نهائي.

إذا لم يظهر الـArtifact، فهذا يعني أن تشغيل CI لم يصل بنجاح إلى رفعه بعد؛ لا تفترض وجود APK جاهز ولا تستخدم ملفاً من بناء غير متحقق.

## الصور والوسوم

- الاختيار يتم عبر منتقي مستندات Android، مع طلب الملفات المحلية فقط. المدعوم حالياً صور JPEG وPNG حتى 20 MiB و16 مليون بكسل؛ الصور غير المدعومة لا تدخل مجموعة الوسوم.
- لا يُحفظ اسم الملف أو مساره أو بيانات OCR. هوية الصورة SHA-256 من بايتات الأصل. التطابق التام يُظهر تنبيهاً ولا يدمج السجلات ولا يستبدل الوسم. dHash يسجل مجموعة تقارب منفصلة ولا يدمج الصور المتشابهة.
- المعاينة تُطبّق اتجاه EXIF قبل رسم إحداثيات `[x,y]` المطبّعة إلى `[0,1]`. يمكن تكبيرها وتحريكها، وإضافة المستندات المتعددة، وترتيب الرباعي `TL→TR→BR→BL`، أو تسجيل الحدود الجزئية/المحجوبة وغير القابلة للتحديد.
- حالات الصورة والمصدر والجودة والصعوبة، نوع المستند، جودة القص، التحقق البشري، المراجعة الثانية والتحكيم حقول مستقلة. تبقى `ai_suggestions` منفصلة ولا تتحول إلى اعتماد بشري تلقائياً.

## لماذا طبعة Android أصلية وليست HTML أو PWA؟

ملف `file://` وحده لا يثبت وجود تطبيق مثبت أو مساحة ملفات قابلة للكتابة والاستعادة. أما PWA فتحتاج آلية تثبيت/تخزين المتصفح، وتخضع بيانات المتصفح لسياسات المساحة والإخلاء ولا تضمن حفظ الصور بعد إعادة التشغيل أو إزالة البيانات. لذلك اختيرت طبعة Android أصلية تستخدم منتقي المستندات ومساحة التطبيق الخاصة، مع JSON صريح عبر منتقي Android كنسخة استعادة ينقلها المستخدم محلياً. لا يحتاج التطبيق إلى خادم ويب أو WebView أو خدمة إنترنت، ولا يدّعي أن PWA أو `localStorage` وسيلة حفظ موثوقة.

## التخزين والاستعادة دون اتصال

المسودات والصور المختارة تحفظ في مساحة التطبيق الخاصة (ملف مسودة ذري وصور مسماة ببصمة SHA-256)، لا في `localStorage` أو مجلد عام. تظهر بعد إغلاق التطبيق وإعادة فتحه على الجهاز نفسه، لكنها **تُحذف عند إزالة التطبيق أو مسح بياناته**.

لنسخة احتياطية قابلة للنقل:

1. اضغط «حفظ JSON محلياً» واختر مجلداً محلياً من نافذة Android. لا تشارك الملف ولا تحفظه في مزود سحابي.
2. احتفظ بالصور الأصلية في تخزينك المحلي. ملف JSON لا يحتوي الصور أو أسماءها أو مساراتها.
3. بعد التثبيت مجدداً، استورد JSON، ثم اختر الصور الأصلية نفسها عند الحاجة لإرفاقها. تتم المطابقة على SHA-256. إذا تكرر سجل موجود، يعرض التطبيق خيار الاحتفاظ بالعمل المحلي أو استبدال سجل مطابق بموافقة صريحة؛ لا يوجد دمج أو استبدال صامت.
4. لا تحتوي بيانات JSON على الصور نفسها؛ استيراد JSON وحده يعيد الوسوم فقط. يجب أن تبقى الصور الأصلية متاحة محلياً لإعادة الإرفاق وعرضها.

حد ملف JSON هو 128 MiB. اختبر التطبيق ببيانات وصور اصطناعية فقط عند تطويره. لا تضع صور هويات أو تعليقات حقيقية في Git أو CI.

## التحقق

يجب تشغيل `dart format`, `flutter analyze --fatal-infos`, `flutter test`, وبناء flavor الأداة، إضافة إلى اختبارات Python لمدقق v2 وفحوص المصدر والصلاحيات. بناء CI ليس اختباراً على هاتف. يظل المخطط `scan-id-local-annotations-v2` والإصدار `2.0.0`، والمرجع المستقل هو `tool/validate_local_annotations.py` و`tool/schemas/local_reference_dataset_v2.schema.json`.
