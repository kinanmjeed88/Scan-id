# التوسيم المحلي لمجموعة Scan-id

**الحالة:** أداة محلية جاهزة؛ لا توجد وسوم بشرية أُنشئت أو أُقرّت بهذه الأداة حتى الآن.

## الخصوصية

تعمل `tool/local_annotation_studio.html` كملف ثابت في المتصفح، بلا خادم وبلا CDN أو طلبات شبكة (`connect-src 'none'`). يختار المراجع الصور من جهازه؛ تُحسب بصمة SHA-256 داخل المتصفح وتظل الصور في ذاكرة التبويب. لا يُنزّل إلا JSON للوسوم عند الضغط على زر التصدير. لا ترفع الصور أو النصوص أو ملف الوسوم إلى CI أو خدمة خارجية، ولا تضعها في Git. مجلد `local-data/` متجاهل في `.gitignore`.

معرّف العينة هو بصمة محتوى كاملة، لذلك يعدّ ملف الوسم نفسه بيانات محلية حساسة حتى لو لم يحمل أسماء الملفات. الواجهة لا تعرض أسماء الملفات ولا تضع بايتات الصور داخل JSON؛ تبقى الصور في ذاكرة التبويب أثناء المراجعة. ملف JSON نصي غير مشفّر: احفظه على قرص مشفّر، وأوقف المزامنة/النسخ السحابي، ولا ترفعه. عند إغلاق التبويب تُمسح الصور من ذاكرة الجلسة؛ نزّل ملفك المحلي أولاً.

## تشغيل المراجعة المستقلة

1. افتح `tool/local_annotation_studio.html` مباشرة في Chrome أو Edge حديثين، وأدخل رمزاً مثل `R1` لا اسماً شخصياً.
2. اختر الصور الثابتة فقط من مجموعة `Mostmskat/`. لا تختَر الفيديو أو نسخة المشروع الاحتياطية. الملفات المكررة المحتوى تُدمج حسب البصمة.
3. عيّن رمز جلسة/مصدر غير شخصي مثل `session-01` فقط عندما تعرف أن الصور من الالتقاط نفسه. لا تستنتج الجلسة من الاسم أو الرقم داخل اسم الملف.
4. علّم الخلفية السلبية أو عدد المستندات، واختر الأنواع الموجودة فعلياً في `DocumentKind`: البطاقة الوطنية، بطاقة السكن، جواز السفر، البطاقة التموينية، أخرى، أو غير معروف.
5. للمستند الظاهر بالكامل، انقر الزوايا الأربع بترتيب عقارب الساعة بدءاً من أعلى اليسار. للمستند المقطوع/المحجوب، ارسم الجزء المرئي فقط ولا تخمّن الزوايا غير المرئية. سجّل الحالات غير القابلة للوسم صراحةً.
6. سجّل قبول حد القص وفق الرؤية البشرية وحدها؛ لا تعرض على المراجع مخرجات النموذج أثناء الوسم. يمكن إدخال transcript OCR كاملاً (بما فيه الأرقام) فقط بعد مطابقته حرفياً مع الصورة، ثم فعّل خانة التأكيد اليدوي. قد يحتوي النص بيانات هوية؛ ملف الوسوم يصبح حساساً ويجب أن يبقى محلياً وخارج Git/CI والخدمات الخارجية. لا تعرض النص على logs أو تقارير مشتركة.
7. نزّل ملف المراجع الأول، ثم كرر من جلسة/ملف مستقل للمراجع الثاني دون اطلاع متبادل. الاستئناف مسموح فقط بملف يحمل رمز المراجع نفسه.
8. بعد الحفظ المستقل، شغّل مدقق الاتفاق محلياً. يقارن إجمالياً حالة العينة والجلسة، وعدد المستندات والخلفية، والتصنيف والظهور وجودة القص ومؤشرات الجودة، وتوفر الحدود واتفاقها، وتغطية/نص OCR. تشمل الخلافات حدوداً غير متطابقة أو غير قابلة للمطابقة مكانياً. المخرجات لا تكشف معرفات العينات أو النصوص؛ استخدم ملفات الوسم المحلية والصورة للتحكيم، ولا تُحوّل متوسط الحدود إلى «حقيقة» تلقائياً.

مثال تحقق محلي (المسارات محلية ولا تُرسل). عرّف أولاً عتبة اتفاق الحدود بعد اعتمادها كتابةً وقبل النظر إلى نتائج المراجعين؛ لا توجد قيمة مفترضة في المستودع:

```sh
export PRE_REGISTERED_ANNOTATOR_IOU='<approved-number-between-0-and-1>'
python3 tool/validate_local_annotations.py local-data/review-R1.json \
  --compare local-data/review-R2.json \
  --polygon-iou-review-threshold "$PRE_REGISTERED_ANNOTATOR_IOU" \
  --require-complete
```

المخرجات تجميعية ولا تطبع معرّفات العينات أو النصوص. الخيار `--require-complete` يرفض الوسوم غير المكتملة أو غير المحكّمة. لا تُستخدم عتبة اتفاق الموسّمين لضبط عتبات النموذج.

## التقسيم قبل قياس النماذج

لا تقسم الصور عشوائياً على مستوى الصورة. بعد المقارنة، ينشئ المحكّم ملفاً مستقلاً بمعرّف `ADJ1` ويعلّم كل عينة «حُكِّم يدوياً». يجب تعيين **مصادر/جلسات الالتقاط** كاملة إلى مجموعة واحدة فقط. لا تفترض نسب تدريب/تحقق/اختبار أو تعيّن مجموعة الاختبار بعد رؤية أداء النموذج. أنشئ ثلاثة ملفات نصية محلية، واحداً لكل مجموعة، يحتوي كل منها رمز جلسة واحداً في السطر، ثم نفّذ:

```sh
python3 tool/create_local_evaluation_splits.py \
  --annotations local-data/adjudicated.json \
  --train-groups local-data/train-groups.txt \
  --validation-groups local-data/validation-groups.txt \
  --test-groups local-data/test-groups.txt \
  --output local-data/evaluation-splits.json
```

تتطلب الأداة أن تكون كل العيّنات محكّمة، وأن تكون لكل عينة جلسة معروفة، وأن تغطي ملفات المجموعات الجلسات كلها دون تداخل. لا تحسب هذه الأداة دقة نموذج؛ تنشئ manifest للتقسيم وتطبع أحجام المجموعات وفئاتها إجمالياً فقط. ينبغي تثبيت المقاييس والعتبات مسبقاً واستخدام validation للتطوير؛ لا تستخدم test لضبطها.

## جرد محلي غير موسوم (2026-10-26)

أُجري فحص محلي إجمالي للبيانات الوصفية دون طباعة أسماء أو مسارات أو قيم EXIF: **19 صورة ثابتة قابلة للفك من 19**، و18 قياساً مميزاً للأبعاد، ولا صور متطابقة بايتياً. لم توجد طوابع زمنية أصلية لالتقاط الصور أو بيانات طراز كاميرا قابلة للاستخدام لتكوين جلسات؛ لذلك لا يمكن صنع تقسيم source/session تلقائياً أو بأمان من metadata.

قُرئ ترويس وmanifest نسخة `.scanid` محلية دون استخراج payloads: تضم metadata فيها 14 asset و14 عنصر تخطيط وسجلاً واحداً، مع 6 وصفات قص و4 حدود مقترحة ووسم قص يدوي واحد و5 عناصر بمقاس مؤكد. لا توجد فيها سجلات توسيم مستقل أو مراجع OCR؛ هذه حقول تطبيق/قرارات سابقة بلا تحكيم أو provenance يثبت صحتها، ولذلك **لم تُعامل كـground truth** ولم تستخدم لإنشاء labels أو splits.

## حدود الأداة والحالة الحالية

- الأداة لا تولّد أي تسمية تلقائية، ولا تستنتج نوع المستند من اسم الملف أو نسبة الأبعاد، ولا تنتج transcript.
- «مراجعة مكتملة» لا تعني أن الوسم صحيحاً؛ يلزم استقلال المراجعين والتحكيم اليدوي.
- لا توجد حالياً مجموعة موسومة مزدوجاً أو تقسيم ملتقط حسب الجلسة، لذا لا توجد precision/recall أو IoU مرجعية جديدة ولا مبرر لتدريب نموذج أو ضبط عتبة.
- الملفات المحلية المعروفة تضم 19 صورة ثابتة ومادتي فيديو/نسخة احتياطية غير مدرجتين في الأداة. بقيت الملفات الـ21 على الجهاز لكنها أزيلت من فهرس الفرع الحالي وأضيف `/Mostmskat/` إلى التجاهل. كانت هذه المواد موجودة في تاريخ Git للفرع الأساس `searchidf` وللرؤوس السابقة؛ حذفها من الشجرة الحالية لا يمحو blobs أو commits سابقة ولا يحقق تطهيراً تاريخياً. لم تُعد كتابة `searchidf` أو أي تاريخ منشور؛ يلزم مالك المستودع لمعالجة سجل النشر إن طلب ذلك.
