**الحكم:** المشروع غير مكتمل، والمرحلة الأولى غير معتمدة بعد. لا نسخة Windows/Android مبنية أو مختبرة في هذه الجلسة.

## 1. ما وُجد عند التدقيق

المستودع كان يحتوي `README.md` فقط. لا تطبيق سابق أو API أو اختبارات تحتاج الحفاظ عليها. المضيف Linux x86_64 دون Flutter/Dart/Java/Android SDK وأدوات Windows. فشلت محاولات الوصول إلى مخازن SDK وPub بخطأ TLS، بينما أمكن فحص ملفات المنبع عبر GitHub API.

وثيقة [المعمارية](ARCHITECTURE.md) كُتبت قبل الشيفرة، وتحدد المخطط، فصل الطبقات، الاعتماديات وتراخيصها، مخاطر الذاكرة والطباعة ومراحل القبول. تقييم التوافق عملياً ما زال معلقاً؛ لا تُعتبر معاينة ملفات المكتبات اختباراً لها.

## 4. الاختبارات المكتوبة

**49 اختباراً معلناً في ثمانية ملفات اختبار — جميعها بانتظار التشغيل.**

- النموذج: 10 — round-trip، النسخ immutable، أنواع ومدخلات فاسدة، مخطط مجهول، معرّفات مكررة، أصول مفقودة، ملكية الملفات، مسارات غير آمنة، حدود وأبعاد وهوامش.
- الهندسة: 7 — تحويل mm إلى pixels/points، A4 عند 300/600 DPI، دوران حول المركز، التلامس مقابل التداخل، رباعي صالح/متقاطع/مقلوب/منعدم وحدود حجم الناتج. لا تختبر هذه الاختبارات تصحيح منظور لم يُنفذ.
- سجل التراجع: 4 — undo/redo، فرع جديد بعد undo، سعة محدودة، إعداد غير صالح.
- التخزين: 8 — إعادة فتح قاعدة ملفات فعلية، تعارض مراجعات، عمليتا حفظ متنافستان، ملف مفقود، حذف بيانات دون الصور، مخطط مستقبلي، ورفض symlink. اختبار symlink معلّم للتخطي على Windows بسبب امتيازات إنشاء الروابط.
- المعالجة الأولية: 6 — PNG/JPEG، الأصل لا يتغير، EXIF، صورة مصغرة، حجم ترويسة كبير، صور تالفة/كبيرة/متحركة.
- قارئ الترويسة: 3 — JPEG ضخم، مقطع ناقص، PNG بمقاس صفر.
- خدمات الاستيراد: 8 — مسار استيراد إلى الملفات والقاعدة ثم إعادة الفتح، نجاح جزئي، تعارض حفظ وإبلاغ الملفات المتبقية، قراءة محدودة، فشل decoder، إلغاء، فشل كتابة القاعدة، إزالة مرجع وحماية الصورة المستخدمة.
- Widgets: 3 — إنشاء/تسمية/فتح، رفض اسم فارغ وإلغاء، مقاس هاتف وإلغاء اختيار الصور.

كل الصور في الاختبارات مولّدة اصطناعياً؛ لا مستمسكات شخصية أو ملفات ضخمة أو SDK محفوظة في Git.

## 5. القيود والأعمال المتبقية

1. **غياب SDK عائق تحقق فعلي.** يجب حل الاعتماديات، مراجعة `pubspec.lock`، وتشغيل التنسيق والتحليل والاختبارات قبل اعتماد المرحلة الأولى أو الانتقال إلى القص.
2. لا توجد كاميرا، قص تفاعلي، كشف حواف، homography، محرر A4، محاذاة، ترتيب ذكي، تصدير أو طباعة. نماذجها ليست تنفيذاً لوظائفها.
3. إعادة ترتيب/تكرار/إعادة تسمية الصور والتحديد المتعدد غير متوفرة؛ الاستيراد المتعدد فقط متوفر في الشيفرة.
4. الحذف الحالي يزيل سجلاً أو مرجعاً؛ تبقى الأصول المحلية. لا واجهة استعادة للمحذوف ولا GC. قد تترك كتابة ملفات ناجحة تليها transaction فاشلة أو إغلاق مفاجئ ملفات يتيمة. هذا تفضيل لحماية البيانات، وليس نسخة احتياطية أو استرداداً مكتملاً.
5. لا اختبار تعطل قسري، امتلاء مساحة حقيقية أو انقطاع طاقة. اختبار فشل الكتابة الحالي حقن خطأ في واجهة المستودع فقط. لا يُضمن حفظ عملية لم يكتمل commit لها، وPopScope ليس منعاً لإغلاق نافذة Windows أو قتل العملية.
6. حد 16MP/20MiB ليس حد peak RSS. بيانات PNG المضغوطة الإضافية/الملفات الخبيثة تحتاج hardening وfuzzing، والمكتبات المثبتة تحتاج تدقيق تحديثات أمنية قبل الاستخدام الإنتاجي. فحص ترويسة لا يجعل decoder آمناً لكل مدخل عدائي.
7. فحوص المسارات لا تحمي من برنامج محلي ذي الصلاحيات نفسها يبدّل روابط/ملفات بالتزامن بين الفحص والاستخدام؛ مساحة التطبيق الموثوقة هي حد الثقة الحالي.
8. لا دعم HEIC/WebP/TIFF/PDF أو الصور المتحركة، ولا تشفير إضافي، ولا نسخ احتياطي داخل التطبيق. حذف بيانات التطبيق/إلغاء تثبيته قد يفقد المشاريع. أصول EXIF تُحفظ كما هي.
9. لا نموذج تعافٍ لقاعدة تالفة أو ملف مشروع منفرد فاسد بعد؛ تظهر رسالة خطأ ولا تُعاد كتابة القاعدة. قد يمنع سجل غير صالح عرض قائمة المشاريع حتى إصلاح/استعادة البيانات بأداة لاحقة.
10. سياسات Android تحتاج اختبار الدمج على النظام/OEM. Flutter يضيف إذن شبكة إلى debug/profile لأدوات التطوير؛ يجب تدقيق الـ release merged manifest عند أول بناء. لا تستطيع سياسة التطبيق منع backup خارجي يجريه مستخدم الجهاز.
11. بناء Android الافتراضي — عند نجاحه لاحقاً — بتوقيع تطوير، وWindows portable غير موقّع. إعداد installer والتوقيع مرحلة تسليم لاحقة.
