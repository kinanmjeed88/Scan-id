# ADR-002 — Deterministic A4 layout is the sole placement authority

- **Status:** Accepted
- **Date:** 2026-10-08

## Context
Recognition will produce evidence (detection, geometry, type, preset,
confidence). The existing layout engine — `arrangeDocuments`
(`lib/domain/arrangement.dart`) and `proposePacking` (`lib/domain/packing.dart`)
— already decides page, x, y, rotation, packing, collisions and page count
deterministically, in millimetres, honoring locks, gaps and `keepPlaced`.

## Decision
AI/recognition may **propose** evidence only. It must **never** generate final
A4 coordinates. Physical placement (page index, x, y, rotation, packing,
collision avoidance, page utilization) is decided **exclusively** by the
existing deterministic engine. The engine remains ignorant of AI.

## Consequences
- Recognition output is an input to layout (a `DocumentLayoutItem` with a
  confirmed physical size in mm), not a set of coordinates.
- Determinism guarantees (stable ordering, locked items never moved, mm units)
  are preserved and must be covered by regression tests.
- Any future keep-together group constraint (front/back pairs) is added as a
  **generic** constraint the engine evaluates; the engine does not learn what a
  "pair" or "document type" means.

## Alternatives considered
- Letting a model emit coordinates — rejected: non-deterministic, unauditable,
  and contradicts the mission ("AI is an assistant; the user and the
  deterministic engine decide").
