# ADR-006 — Classical CV is retained and extended before any learned detector

- **Status:** Accepted
- **Date:** 2026-10-08

## Context
`suggestDocumentCorners` (`lib/imaging/document_detector.dart`) is a
deterministic, purely-local classical detector (Otsu background segmentation +
gradient-directed Hough quadrilaterals + sub-pixel edge refinement). It returns
a single quad or `null`. It is a reusable foundation, not a liability.

## Decision
Retain and **extend** the classical detector (multi-document candidates,
corner refinement, `geometryConfidence`) before introducing any learned
detector. A learned detector is **conditional** on Phase 7 evaluation evidence
against a real, representative dataset (Phase 9), with its own ADR, size and
license review.

## Consequences
- No heavyweight ML/native dependency is added merely because it is fashionable.
- Detection improvements are measurable with synthetic fixtures and, later, the
  owner's real dataset.
- The hybrid design (classical proposal + geometric validation + OCR evidence +
  classifier evidence) stays explainable.

## Alternatives considered
- Adopt an off-the-shelf detection model immediately — rejected: unproven on
  Iraqi documents, adds native runtime/size/license cost without evidence, and
  contradicts "detector selection must be evidence-based".
