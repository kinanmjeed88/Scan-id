# ADR-007 — OCR is evidence, not the sole classifier

- **Status:** Accepted
- **Date:** 2026-10-08

## Context
OCR will provide label anchors and structural evidence for Arabic documents.
The classifier must combine independent evidence (visual model if any, OCR
evidence, geometry/aspect, structure) via fusion (see `docs/AUDIT.md` §Fusion).
Rule R1 requires automatic eligibility to need at least two independent sources,
at least one of them not OCR.

## Decision
OCR output is **evidence only**. Raw OCR text stays in memory, is never logged
or persisted, and personal field values are never extracted or stored. OCR-only
(or any single-source) results are capped into the review band and are never
auto-eligible. Insufficient evidence returns `Unknown`.

## Consequences
- `OCRAnalyzer` sits behind an interface, loaded once per worker, with graceful
  fallback when it fails (the pipeline continues with the other evidence).
- Fusion and the R1–R4 hard rules are pure, property-tested domain logic.
- No OCR text or field values are written to the database or backups.

## Alternatives considered
- Treat OCR text as the classifier — rejected: brittle, language/quality
  sensitive, and would store sensitive text.
