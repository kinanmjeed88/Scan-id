# تصحيح سياسة الإنتاج: C60 وحدود55

التاريخ: 2026-11-09. هذه السياسة تحل محل إبقاء الإنتاج عند70% في تقرير التنفيذ السابق؛ تقرير التدقيق والتقارير الأقدم لقطات تاريخية وليست إعدادات النسخة الحالية.

## القرار الفعلي

- `classificationAcceptanceThreshold=.60`، و`boundaryAcceptanceThreshold=.55` (مع alias التوافق `automaticAcceptanceThreshold=.55`). عتبة الحد الأدنى للتصنيف وتعليمات المراجعة مشتقة من سياسة C وليست حدًا خفيًا عند70%.
- `classifyDocument`: C هو دليل OCR الدلالي المستقل والوَحيد. لا يحل اسم ملف أو شكل أو D أو G أو OCRmean محل هذا الدليل. لا تنتج النتائج الجديدة F مدمجة؛ يبقى حقل F القديم قابلًا للقراءة من المشروعات السابقة دون استخدامه للقبول أو أهلية A4. نسخة المصنف `explicit-evidence-4` وpipeline `smart-5`.
- `qualifiesForAutomaticPlacement` يفحص نوعًا معروفًا وحالة recognized ومرشحًا وحيدًا وC≥60% فقط. تبقى شروط الحدود المعتمدة والقص والمقاس الموثق وتوافق النسبة في SmartIntake مستقلة. لا يمنع انخفاض D/G/F قبول النوع، ولا يمنح ارتفاع C إذن قص.
- يحفظ SmartIntake ثقة العنصر من C لا F، وأسباب الرفض لا تتذرع بدرجة إجمالية أو70%. شاشة المراجعة تعرض ثقة النوع، والتشخيص لا يجعل F سببًا لرفض تلقائي.
- DocQuadNet وDocAligner يستعملان سياسة55% نفسها. cascade يشترط اتفاق الزوايا وأن يجتاز **كلا** الاقتراحين قرار السلامة والدرجة؛ نموذج ثانٍ دون55% لا يؤيد الأول. الاقتراح الوحيد أو اختلاف النموذجين أو flags المراجعة يبقى يدويًا.
- الهندسة والمساحة والأضلاع والتقاطعات وframe-touch والمنظور والتحكيم لم تُخفّض. ثُبّت باختبار انحدار أن التحكيم يحيل learned inner frame الحاد للمراجعة عند وجود حد خارجي صالح ومختلف ماديًا؛ لا تسمح قوة gradient أو score وحدها بقص هوامش المستمسك أو اختيار إطار خارجي بديل تلقائيًا.
- يظل fallback الكلاسيكي review-only. لا يعني55% أن الرباعي صحيح فيزيائيًا بكل صورة؛ هذه سياسة قبول مشروطة بالأدلة والحواجز، وليست دقة معايرة.

## مصفوفة دورة الحياة

| النوع | الحدود | المقاس | النتيجة |
|---|---|---|---|
|C≥60% وأدلة مستقلة وحيدة|نموذجان مؤيدان وآمنان≥55%|موثق ومتوافق النسبة|قص وترتيب A4|
|مقبول|غير محسومة أو دون55%|أي حالة|حفظ النوع، مراجعة القص دون إعادة فرض اختيار النوع|
|غير محسوم أو OCR فاشل|آمنة|غير مؤكد|حفظ القص والأصل، طلب النوع/المقاس عند الحاجة|
|مقبول|آمنة|تقديري أو مفقود|حفظ القص والنوع خارج A4 حتى تأكيد المقاس صراحة|

نوع مستمسك وحده لا يحول estimate إلى قياس موثق. `confirmManualBoundary` و`extractManualDerivedDocument` لا يؤكدان مقاسًا تقديريًا تلقائيًا دون customSizeMm صريح. حوار النوع الذي يعتمد اقتراحًا هندسيًا يفتح مراجعة المقاس إذا بقي غير مؤكد؛ لا يلزم إعادة رسم القص المحفوظ. حقول المقاس المعروضة يمكن تأكيدها أو تعديلها صراحة. لا تُفرض النسبة المليمترية على pixels؛ وصفة المعاينة محفوظة وcontain مسؤول عن ملاءمة slot دون مط.

## الاختبارات

- عُدلت عقود70% المتعارضة في قرار الحدود والمصنف وinference للنموذجين والتشخيص وسياسة المراجعة.
- اختبار إنتاج تكاملي جديد `test/application/production_acceptance_policy_test.dart`: نفس الإعدادات الافتراضية المشحونة، C60/B55/مقاس موثق →A4؛ C60/B54.9 →حفظ النوع؛ C59.9/B55 وOCR exception/B55 →حفظ القص؛ مقاس تقديري →off-sheet. التخزين والقص والترتيب حقيقية، OCR ودرجات النموذجين محقونة، والأصل يطابق bytes المستوردة بعد إعادة التحميل.
- اختبارات المصنف تثبت أن F منخفضة/غائبة وD ضعيفة لا تمنع C60، وأن النتائج الجديدة لا تصنع F.
- اختبارات الهندسة ترفض أقل55% والتقاطعات والرباعيات الصغيرة/frame والدرجات غير الصالحة، وتحافظ على العتبة الأشد إذا طلبها proposal صراحة.
- اختبارات cascade: نموذجان عند55% مقبولان عند السلامة؛ نموذج ثانٍ عند54.9% أو الاختلاف لا يمرران القص.
- اختبار inner-frame يثبت المراجعة حتى عند99% رغم حدة الإطار الداخلي إذا ثبت وجود حد خارجي صالح يحتويه. لا يدعي اكتشاف كل إطار داخلي في كل صورة بلا دليل خارجي.
- اختبارات عدم تغيير pixels بالمقاس واستعادة المشروع والوجوه وpacking/export باقية ضمن المجموعة الكاملة.

## التحقق

الفحوص الساكنة وImports وGit Diff محليًا؛ Flutter/Dart غير متاحين محليًا، ومحاولات analyze/test/build Android/build Windows تعذرت بـexit127. يستخدم التحقق الفعلي على Flutter أدوات GitHub Actions، وتُذكر نتيجته ورابطه وSHA الكامل في رسالة التسليم بعد انتهائه. نجاح تشغيل الالتزام السابق لا يُنسب لهذه السياسة.

لا تغيير schema أو اعتماديات التطبيق أو مفاتيح إصدار، ولا Merge أو نشر Release. CI قد يبني R8 بمفتاح اختبار مؤقت كاختبار فقط. لا ادعاء بدقة ميدانية أو طباعة على ورق فعلي.
