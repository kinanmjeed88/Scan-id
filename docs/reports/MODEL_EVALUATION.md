## التفسير والقيود

لا توجد تسميات بشرية مستقلة لعدد الوثائق أو حوافها أو قبول القص، ولا split اختبار مستقل. لذلك لا يمكن تحويل `accepted` إلى «صحيح» أو `needsReview` إلى «خطأ». الاختلاف بين المسارين يصف السياسة/المخرجات فقط؛ لا يحدد أيهما أدق ولا يبرر تخفيض العتبات. لا توجد precision أو recall أو IoU أو معدل قص خاطئ صالح للإعلان.
