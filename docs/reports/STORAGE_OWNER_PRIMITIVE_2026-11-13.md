# تجربة مرشّح استبعاد مالك التخزين — غير مكتملة

## الحكم

**FAIL للإغلاق:** لم يُنفّذ مالك Sembast في التطبيق، ولا بروتوكول دورة حياة الملفات. لا يُعتبر هذا الاختبار حماية للتطبيق، ولم تُفعّل اختبارات سلامة سباق المراجعات أو الاستعادة. بقيت الاختبارات التشخيصية الثلاثة دون تعديل.

## التجربة المضافة

`test/tool/test_storage_owner_primitives.py` يختبر بدائل منخفضة المستوى فقط، باستخدام ملف مؤقت وعمليات Python حقيقية تتزامن برسائل عبر pipes، بلا `sleep` أو mutex وهمي:

- على Linux: `flock` الحصري غير المحجوب على واصفات ملفات مفتوحة بصورة مستقلة. فحص محلي أكد رفض واصف ثانٍ في العملية نفسها ورفض عملية ثانية، ثم نجاح عملية جديدة بعد الإغلاق العادي وبعد قتل المالك، مع بقاء اسم الملف.
- على Windows: اختبار مرشح `CreateFileW` مع `OPEN_ALWAYS` وعدم السماح بالمشاركة، للفحوص نفسها. أضيف إلى وظيفة Windows في Actions؛ لا تُدّعى نتيجته حتى نجاح تشغيل SHA المحتوي عليه.

الملف نفسه ليس دليلاً على الملكية، ولا يُحذف أثناء التجربة إلا بعد إغلاق كل المقابض. هذه التجربة لا تستخدم Sembast أو Dart FFI أو قفل التطبيق، ولا تختبر Android أو ديمومة العمليات أو الاستعادة أو الحذف. نتيجة Linux المحلي لا تثبت Android. واجهة Android Bionic تعلن [`flock`](https://github.com/aosp-mirror/platform_bionic/blob/android-14.0.0_r1/libc/include/sys/file.h)، لكن الإعلان ليس اختباراً على Android ولا ضماناً لجميع أنظمة الملفات.

أُضيف اختبار المرشح إلى بوابات Python على Linux وWindows بصورة دائمة، وليس إجراء CI مؤقتاً؛ لا يستخدم صوراً أو بيانات شخصية. لا يغير ذلك الاعتماديات أو سلوك المنتج. يجب إثبات ربط أي قفل مختار بعمر جميع مسارات `open/recover/close` ومنع فتح آخر عبر isolates والعمليات، ثم اختبار مالك التطبيق الحقيقي على Android وWindows والانهيار وإعادة الفتح.

## معايير القبول

| المعيار | الحكم |
|---|---|
| استبعاد واصف مستقل وعملية وموت مالك لمرشّح Linux المحلي | **PASS للتجربة فقط**. |
| مرشّح Windows | نتيجة Actions على آخر SHA؛ ليست اختباراً لقفل التطبيق. |
| ملكية Sembast الحقيقية ومنع نسخة قديمة | **FAIL**؛ لم يُنفّذ المالك. |
| المنتجون والاستعادة والحذف وpending journal | **FAIL**؛ لم يُنفّذ بروتوكول موحد. |

| فشل قراءة المراجع بالتزامن | **NOT VERIFIED**. |
| اختبارات وبناء آخر SHA | تُقرأ من تشغيل Actions للـSHA الأخير، ولا تعني إغلاق العيب. |
