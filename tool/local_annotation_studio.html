الخصوصية قبل البدء
  • اختر الصور فقط؛ لا تختَر الفيديو أو نسخة المشروع الاحتياطية.
  • تُقرأ الصور داخل تبويب المتصفح، وتُحفظ التسميات فقط عند تنزيل ملف JSON يدوياً.
  • لا تظهر أسماء الملفات في الواجهة أو ملف الوسم. معرّف الصورة هو SHA-256 محلي لمطابقة مراجعتين؛ اعتبر ملف JSON خاصاً ولا ترفعه إلى Git أو CI.
  • مرجع OCR اختياري: لا تدخله إلا بعد مطابقته حرفياً مع الصورة. قد يتضمن أرقاماً أو بيانات شخصية؛ ملف JSON الناتج حساس، فاحفظه محلياً فقط ولا ترفعه إلى Git أو CI أو خدمة خارجية.
  • للمراجعة المستقلة: لكل مراجع ملف منفصل، ولا يطّلع أحدهما على وسوم الآخر قبل الحفظ.
